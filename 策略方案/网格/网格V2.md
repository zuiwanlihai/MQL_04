# 优化网格策略方案

> 本方案用于策略设计与回测验证，不构成收益保证。文中参数是测试起点，应结合品种合约规格、交易成本与历史行情验证后再决定是否实盘使用。

## 一、策略目标与适用行情

将基础固定网格改为**带行情过滤和风险上限的区间网格**。策略仅在判断为区间或弱趋势行情时建立新仓；趋势增强、数据异常或风险预算用尽时停止加仓，并按预设规则退出已有仓位。

网格策略通过价格往返赚取区间波动，主要风险是单边行情中逆势仓位持续累积。因此，行情过滤用于减少不适合的入场，硬性风险退出用于限制已有仓位的损失，两者不能相互替代。

## 二、行情过滤

建议先以 **H1** 周期回测，使用 ADX(14)、EMA(50) 和 ATR(14)：

| 行情状态 | 判断条件 | 策略行为 |
| --- | --- | --- |
| 区间候选 | ADX(14) < 20，且 EMA(50) 最近 10 根 K 线变化幅度 < 0.5 × ATR(14) | 允许按网格规则开新仓 |
| 趋势增强 | ADX(14) ≥ 25，或 EMA(50) 最近 10 根 K 线变化幅度 > 0.8 × ATR(14) | 停止开新仓；依据风险退出规则处理已有仓位 |
| 灰区/数据不足 | ADX 处于 20–25，EMA 变化处于灰区，或指标所需历史数据不足 | 不增加仓位；等待条件明确 |

EMA 变化幅度应以同一价格单位计算，并与 ATR 比较。过滤器只控制是否建立新仓，不得用“行情过滤通过”作为取消止损或风险限制的理由。

## 三、网格结构与锚定

### 网格间距

每轮网格开始时计算：

```text
网格间距 = max(1.2 × ATR(14), 3 × 当前点差)
```

所有变量须先换算到统一的价格单位。若策略参数以券商 point 表示，需使用对应品种的 `point` 转换，不能把价格距离直接当作点数。应同时核对最小跳动、报价位数及合约规格。

间距在一轮交易期间固定不变，不随每根 K 线动态改变，避免新旧档位错位。只有该轮持仓全部清空后，才能重新计算间距。

### 锚定价

- 新一轮开始时以最新可用报价设定锚定价。
- 只要该轮仍有持仓，就不自动移动锚点。
- 该轮全部仓位平仓后，才重新锚定并启动下一轮。
- 若行情突破最外层网格再多出半格，停止该轮继续开仓，并交由风险退出规则处理；不向趋势方向无限扩展网格。

## 四、开仓与逐笔止盈

- 区间过滤通过时，价格到达锚定价下方档位，可按预设方向规则做多；到达锚定价上方档位，可按预设方向规则做空。
- 初始建议每个方向最多 **3 档**，每档使用固定手数；禁止亏损后加倍手数或其他马丁格尔加仓。
- 每个档位最多持有一笔未平仓订单；下单状态未确认时，应保留档位占用，避免重复下单。
- 多仓价格较实际入场价上涨一个网格间距时，逐笔止盈；空仓价格较实际入场价下跌一个网格间距时，逐笔止盈。
- 入场和平仓按实际成交价、交易方向与可执行报价计算，不假设成交价等于信号档位价。
- 若品种、账户或经纪商不支持可靠的双向对冲，则设置为单方向持仓；不得在未验证保证金和净敞口规则前默认允许双向满仓。

## 五、仓位与风险控制

### 手数预算

每档采用固定手数，不随浮亏增加。手数必须按品种合约规格、账户权益、杠杆、保证金要求以及压力情景损失计算，而不是仅按“网格档数”决定。

回测起始风险预算建议：

- 在压力测试中，单轮网格触及硬止损时的预估净损失不超过账户权益的 **1%**。
- 限制总持仓名义敞口和保证金占用；任一上限达到后不得继续开仓。
- 将多空两侧、同一品种及高度相关品种的敞口纳入账户级风险统计。

1% 是待验证的初始约束，不是适用于所有账户的固定标准。若无法可靠估算最坏情景损失或保证金占用，应先降低仓位或仅做模拟交易。

### 单轮退出与熔断

- 设定账户级单轮最大亏损预算；达到预算后，停止该轮所有新开仓并平掉该轮持仓。
- 该轮亏损退出后进入冷却期；冷却期结束且行情过滤重新通过，才可启动新一轮。
- 若价格突破最外层网格半格，停止对应方向加仓。
- 平仓失败、行情/账户数据缺失、报价异常或状态无法确认时，停止新开仓并发出明确告警；不能将错误当成平仓成功。
- 风险退出规则须覆盖策略进程停止、网关断线、重启和订单状态延迟等情形。策略侧收盘触发不是券商服务器端保护单，不能视为断线保护。

## 六、推荐回测起点

| 项目 | 起始设置 |
| --- | --- |
| 周期 | H1 |
| 趋势/区间指标 | ADX(14)、EMA(50)、ATR(14) |
| 区间候选阈值 | ADX < 20，EMA 变化 < 0.5 × ATR |
| 停止加仓阈值 | ADX ≥ 25，或 EMA 变化 > 0.8 × ATR |
| 网格间距 | max(1.2 × ATR, 3 × 点差)，每轮固定 |
| 每方向最大档数 | 3 |
| 单档仓位 | 固定手数，不递增 |
| 单轮压力损失预算 | 不超过账户权益的 1%（回测起点） |
| 锚点重置 | 仅在该轮仓位全部清空后 |

上述阈值不是已经验证的最优参数。应使用训练区间选择候选参数，并在不同年份、不同市场状态的样本外数据上验证，避免只针对单一历史区间调参。

## 七、回测与验收

回测应尽可能纳入：

- 点差、佣金、滑点、隔夜费及实际成交方向；
- K 线内触发顺序和跳空情况下的成交假设；
- 持仓保证金、强平规则及账户杠杆；
- 趋势行情、跳空、低流动性和波动率突增等压力情景；
- 重启、断线、延迟成交确认、部分成交和手动平仓后的状态恢复。

至少评估以下指标：

1. 扣除全部成本后的净收益及收益稳定性；
2. 最大回撤、最大连续亏损和最长持仓时间；
3. 单轮最大浮亏、止损触发频率和保证金峰值；
4. 分品种、分年份、分趋势/震荡状态的表现；
5. 相邻参数变化后的表现稳定性。

不能只以胜率、交易次数或总收益作为通过标准。若收益依赖少数极端交易、少数年份或非常窄的参数组合，应视为过拟合风险。

## 八、实施前检查

- 统一策略代码、参数面板和模板元数据中的间距单位；明确 `grid_step` 存储的是点数还是价格距离。
- 前端说明须反映真实的方向、锚定、开仓、平仓及风险规则。
- 验证最小报价单位、合约大小、手数步长、保证金和最小止损距离。
- 明确风险预算按账户、策略实例还是单一品种计算，避免多个实例各自满足上限但账户整体超限。
- 在模拟账户中验证订单去重、平仓失败处理、冷却、重启恢复和告警后，再考虑小规模实盘。

**风险提示：**网格策略无法保证盈利。行情过滤、止损和仓位上限只能管理风险；在跳空、流动性不足、交易系统故障或执行延迟时，实际亏损仍可能超过回测估计。
