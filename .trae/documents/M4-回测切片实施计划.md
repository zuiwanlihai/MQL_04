# M4「回测中心」切片实施计划

## Context

M1~M3 已交付（网关绑定、行情数据、策略编辑器+管理）。PRD §M4 与《SDK-v1-API规范》§9 要求本切片落地：子进程沙箱 + import 钩子、回测引擎（逐 bar 回放、三档撮合、账户/保证金模拟）、异步回测任务（队列/进度/超时）、回测报告（指标/权益曲线/交易明细/日志/CSV）与前端回测中心。SDK 的 `shared/sdk/context.py` 目前仅为类型 stub，运行时注入即本切片。

已与用户确认的四个决策：
1. **数据拉取**：扩展网关新增按日期区间端点（`copy_rates_range`），回测 runner 时间窗分页取数。
2. **敏感性对比（P0）**：纳入——创建时可勾选配对，同配置排队保守+标准两任务（共享 group_id），报告页展示年化差值，>5% 标记 ⚠️。
3. **任务队列**：进程内 asyncio 队列（与 heartbeat_loop 同模式）；服务重启时 running→failed（注明中断原因）、pending→重新入队。
4. **版本策略**：允许对未冻结的工作副本发起回测——任务行保存 `source_code` 快照 + version 号（可空）；对冻结版本运行时填充 `StrategyVersion.compiled_at/compile_errors`。

架构总则：**引擎是纯库（in-process 可调、供测试与 M5 模拟盘复用），runner 子进程只是薄传输层；父进程只做编排（取数/编译/spawn/监督/事件落库）**。

## Phase C — 沙箱与引擎（核心）

全部在 `backend/app/sandbox/`：

- `payload.py`：BacktestPayload dataclass + save/load（payload.json + bars.npz，临时目录 `backend/.runtime/backtests/{task_id}/`）。
- `import_hook.py`：三层防御——① `sys.meta_path` finder（**引擎自身 import 全部完成后才安装**；按根模块名白名单 = PRD 标准库清单 ∪ {numpy,pandas,scipy} ∪ app./sdk 前缀）；② 受限 `__builtins__`（删 eval/exec/compile/open/__import__/input/breakpoint，注入受控 __import__）；③ 逃逸成员运行时处置（datetime/random 代理模块剔除 now/utcnow/today/seed 等；numpy/pandas 装载后把 `ESCAPE_MEMBERS` patch 为 raise——表从 `services/strategy_validator.py` 复用，单一事实源）。违规 → SandboxViolationError → fail 事件 + 终止（尽力触发 on_stop）。
- `context.py`：`BacktestContext` 实现 SDK 面——declare 强制、get_bars **按当前索引截断**（未来数据契约运行时执行；count clamp 5000 是策略可见面限制，与引擎全量数据分层）、get_quote 由 bar 派生、账户/持仓只读、buy/sell/close 走撮合、storage 1MB 配额、log 限速 100 条/秒、now=当前 bar 收盘时刻。
- `matching.py`：三档价格公式（MT5 bar 为 bid 口径；spread_i=(bar.spread 或快照点差)×point；滑点不利方向；默认滑点保守 2/标准 1/乐观 0 点）：
  - 保守：开多=次根 open+spread+slip；开空=次根 open−slip；平多=次根 open−slip；平空=次根 open+spread+slip；末根挂单拒绝 MARKET_CLOSED+日志。
  - 标准：当根 close ± 口径同上；乐观：当根 close 无成本。
  - 每笔记录 base_price/spread_cost/slippage_cost/commission。
  - `AccountSim`：手数 volume_step 向下取整（越界 INVALID_VOLUME）、margin=contract_size×volume×price/leverage、free_margin 不足 INSUFFICIENT_MARGIN（业务性继续）、hedging 持仓模型、margin_level<stop_out(默认50) 按浮亏最大逐笔强平、末根收盘强平未平仓（is_forced）。
- `metrics.py`：纯函数指标——bars_per_year=31536000/tf_seconds；Sharpe/Sortino/年化/annual_vol/Calmar/recovery/expectancy/胜率/盈亏比/连胜连败/平均持仓/月度收益/买入持有基准线。
- `engine.py`：`BacktestEngine.run() -> Iterator[EngineEvent]`——装载策略→on_init→逐 bar：ctx._advance(i)、预热期（默认 warmup_bars=100）on_bar 照常但下单拒 WARMUP_PERIOD、**ctx.buy 调用栈内同步重入 on_order**（重入下单计入单 bar ≤20 RATE_LIMITED）、回调 perf_counter>5s→RESOURCE_TIMEOUT 终止、异常→完整 traceback fail、每 bar 估值+保证金检查、progress 事件按步长发出、收尾强平→on_stop→done(report)。
- `runner.py`：`python -m app.sandbox.runner --payload P`——env 自检（BLAS 线程=1/PYTHONHASHSEED=0）、random.seed 固定、装钩子、stdout JSONL 事件（progress/log/signal/trade/equity降采样/done/fail，flush）、**stdin EOF 信标线程**（父进程死→os._exit(143)，防 Windows 孤儿）、退出码 0=done/2=安全终止/3=装载失败。

## Phase D — 任务编排

- `backend/app/services/backtest/data_fetcher.py`：`fetch_bars(...)` 时间窗分页（每页 5000×tf_seconds 滚动、去重排序、含预热向前多取）+ `BACKTEST_MAX_BARS=1_000_000` 入队前预估拒绝 422。
- `backend/app/services/backtest/supervisor.py`：`spawn_and_stream()`——`asyncio.create_subprocess_exec(sys.executable, "-m", "app.sandbox.runner", ...)`（Windows Proactor 事件循环可用，钉死勿切 Selector）、stderr 重定向文件防死锁、RSS 2s 轮询超限杀+RESOURCE_EXCEEDED、总超时 600s 杀+timed_out、取消注册表 {task_id: handle}+psutil 递归杀树。
- `backend/app/services/backtest/queue.py`：`BacktestQueue` 单例——asyncio.Queue + 并发 worker（默认 2）；流水线：CAS 领取（条件 UPDATE pending→running）→ 编译（AST validate + compile()，冻结版本填 compiled_at/compile_errors）→ 取数 → spawn → 事件解析（progress Δ≥1% 或 ≥2s 节流写库；trade/log 批量 flush）→ 终态落库 → 清理临时目录；取消：pending 直接 CAS cancelled，running CAS cancelling+杀进程；`startup_sweep()`：running/cancelling→failed（"服务重启导致任务中断"），pending→重新入队。
- `backend/app/main.py` lifespan：启动队列 worker + sweep；shutdown 取消 worker 并杀全部子进程。
- `backend/app/config.py`：新增 BACKTEST_ENABLED/MAX_CONCURRENCY/TIMEOUT_SECONDS/MAX_BARS/RUNTIME_DIR/STOP_OUT_LEVEL。

## 风险与规避（要点）

- Windows 孤儿子进程 → stdin EOF 信标 + lifespan 显式杀树 + psutil 兜底。
- stdout 管道死锁 → stderr 重定向文件、事件行限长（equity 降采样≤1500、traceback 截断 8KB）。
- 5000 根 SDK 限制 ≠ 引擎数据上限：runner 取数无限制，仅 ctx.get_bars clamp。
- import 钩子误伤引擎 → 引擎 import 全部前置、钩子后装、finder 允许 app./sdk 前缀。
- datetime.now 为 C 方法不可 patch → 代理模块方案 + validator F002 静态层双保险。
- 回调内无限循环无法 5s 处抢占 → 由 10min 总超时杀进程（PRD 既有口径），报告标记。
