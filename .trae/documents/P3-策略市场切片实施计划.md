> 日期：2026-10-12 ｜ 依据：PRD Phase 3 L493「策略市场（仅工具分享，不涉及信号售卖，需法务评审）」

## 1. 概述

实现策略市场最小闭环：**发布（冻结快照）→ 浏览/筛选 → 查看源码 → 一键导入副本 → 下架**。
所有 listings 全用户可见；源码在发布时刻冻结（后续修改原策略不影响市场条目）；
导入产生导入者自己的全新草稿策略。法务边界通过「发布免责确认 + 页面免责声明 + 审计留痕」落地。

**不做**（不预留字段）：评分、评论、计费、信号订阅、版本更新推送。

## 3. 数据模型

### 3.1 新文件 `backend/app/models/market_listing.py`

`MarketListing(BaseModel, kw_only=True)`，表名 `market_listings`：

| 列 | 类型 | 说明 |
|---|---|---|
| id | UUID PK | |
| strategy_id | UUID FK→strategies.id **ondelete=SET NULL**, nullable | 溯源；删原策略不影响市场条目 |
| author_id | UUID FK→users.id **ondelete=CASCADE**, not null, index | 发布者 |
| strategy_name | String(120) | 冻结快照 |
| description | Text, default "" | 冻结快照 |
| language | String(16), default "python" | |
| direction | String(16), default "both" | long_only/short_only/both |
| symbol_ids | JSONB list | 冻结快照 |
| timeframe | String(8), default "H1" | |
| tags | JSONB list | |
| source_code | Text | 冻结源码 |
| source_hash | String(16), index | sha256(source_code)[:16]，防重发布查询 |
| status | String(16), default "active" | active / removed（软删） |
| import_count | Integer, default 0 | |
| created_at / updated_at | 继承 BaseModel | |

`__table_args__`：
- `CheckConstraint("status IN ('active','removed')", name='ck_market_listings_status')`
- `CheckConstraint("direction IN ('long_only','short_only','both')", name='ck_market_listings_direction')`
- `Index('ix_market_listings_status_created', 'status', 'created_at')`
- `Index('ix_market_listings_author', 'author_id')`
- `Index('ix_market_listings_source_hash', 'source_hash')`

> 防重发布用端点查询（同 author + 同 hash + status=active → 409），**不用** DB 唯一约束——
> 允许下架后重新发布同内容、允许不同作者出现相同源码（如各自导入同一模板后转发布）。

## 5. API `backend/app/api/v1/endpoints/marketplace.py`

router = `APIRouter(prefix="/market/listings", tags=["marketplace"])`；在 router.py 挂载：
`v1_router.include_router(marketplace_router, prefix="", tags=["marketplace"])`（prefix 已在文件内）。

| 端点 | 语义 |
|---|---|
| `POST ""` 发布 | 取 strategy（`user_id==current` 否则 404）；`validate_source(source_code)` 失败 → 422（复用 strategies.py 422 响应体风格）；同作者同 hash 且 status=active → 409「已发布过相同内容」；**冻结快照**逐列拷贝（含 source_code），source_hash=sha256[:16]；审计 `market.listing_publish`；201 ListingDetailOut |
| `GET ""` 浏览 | 全登录用户可见；只返回 status=active；join User 取 author_username；query 参数：symbol（JSONB contains）、timeframe、q（strategy_name ILIKE）、sort=latest(默认 created_at desc)｜popular(import_count desc)；分页复用 strategies.py 模式（limit/offset）；200 ListingListResponse |
| `GET "/{listing_id}"` 详情 | status=removed → 404；200 ListingDetailOut（含 source_code） |
| `DELETE "/{listing_id}"` 下架 | 仅 author 本人（否则 404，跨用户不暴露存在性）；软删 status=removed；幂等（已 removed 再删 → 204 不重复审计）；204 |
| `POST "/{listing_id}/import"` 导入 | 函数名 `import_listing`（import 是关键字）；listing 必须 active 否则 404；**防御性二次 validate_source**（DB 内容可能被直改）失败 → 422；创建新 Strategy（owner=current_user，name=请求体 name，description/direction/symbol_ids/timeframe/tags 拷贝，source_code=listing.source_code，status=draft，builder_config=None）；`uq_strategies_user_name` 冲突 IntegrityError → 409「同名策略已存在，请改名」；import_count += 1（同事务）；审计 `market.listing_import`；201 StrategyOut |

注意事项：
- 路由函数内字面量/uuid 无冲突（本 router 无其它字面量 GET）。
- 审计 3 个 action：`market.listing_publish` / `market.listing_remove` / `market.listing_import`，用 `_actor` helper、独立会话（不传 db）。
- 快照语义单测必须覆盖：发布后修改原策略 name/source，listing 不变。
