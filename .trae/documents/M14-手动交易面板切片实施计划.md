# M14 手动交易面板（市价单/平仓/撤单）切片实施计划

## Context（为什么做）

用户选定 P1 项「手动交易面板」，并确认范围：
- **下单能力**：市价买入/卖出 + 持仓全平/部分平 + 查看与撤销现有挂单（**不含**创建限价/止损挂单——网关暂无 `TRADE_ACTION_PENDING` 路径，本次不动网关）。
- **风控与账户**：手动单仍走事前风控闸（`risk.engine.evaluate`）+ 全量审计；可对用户自己绑定的**任意** MT5 账户下单，按 M12 账户→网关节点路由 + 显式登录。

资金安全红线：手动单直连真实券商账户。核心不变量——
1. 每笔手动单先过风控闸（冻结/单笔手数/持仓数/敞口/保证金），被拒绝不下达网关；
2. 每笔下单/平仓/撤单都写审计行（含风控决策）；
3. 账户归属校验：非本人账户 → 404（同 live/paper 所有权模型）；
4. 只读账户（`is_trade_allowed=false`）与冻结账户（`trade_frozen=true`）一律拒绝；
5. 手动单 `magic=0`（MT5 手动单约定），与策略 run 的 magic 隔离，不污染对账归属。

硬约束（沿用）：全中文 UI；MappedAsDataclass 在 DeclarativeBase 前；字面量路由先于 uuid 参数路由；后端无 --reload 改码须重启；emit() 非阻塞渠道派发；PowerShell 用 `;`。

## 设计

### 后端服务 `services/manual_trade.py`（新增）
复用既有件，不重复造轮子：
- `resolve_gateway` + `account_credentials`（M12）解析账户所在节点 URL + 解密凭据。
- `GatewayClient(url)` → `login()` 显式登录绑定账户（失败 → 400 中文）。
- `load_rules("", account_id)` 取账户/全局风控规则（无 run，run_id 传空串）。
- 构造最小 `run` dict 交给 `evaluate(op, symbol, volume, position_id, run, account, positions, rules, symbol_info)`：
  - `run = {"account_frozen": acct.trade_frozen, "halt_until": "", "allocated_capital": 0, "observation_ends_at": None, "lot_cap": 0, "capital_cap_pct": 100, "day_start_equity": 0, "peak_equity": 0}`
  - 冻结账户 → evaluate 第 1 闸直接拒；开仓单跑手数/持仓数/敞口/保证金闸；平仓（op=close）只跑冻结闸（允许减风险）。
- 风控放行 → 调 `place_market` / `close_position` / `cancel_order`；结果 + 审计。
- 审计：`audit_record("manual_order"|"manual_close"|"manual_cancel", actor=user, target_type="mt5_account", params=下单要素, result=success/blocked, risk_decision=verdict)`。
- 总闸：`settings.LIVE_ENABLED` 关闭时 → 409「实盘交易功能未启用」。

### schemas `schemas/trade.py`（新增）
- `ManualOrderRequest`：account_id, symbol, side(buy|sell), volume(gt 0), deviation(默认 20)
- `ManualCloseRequest`：account_id, ticket, volume|None
- `ManualCancelRequest`：account_id, ticket
- `TradeActionResult`：success, order/deal/price/volume, retcode_text, error_code|None, error_message|None
- 读视图复用网关原始 dict（positions/orders/deals 已是普通 dict），端点直接返回 list[dict]（前端渲染）。

### 端点 `api/v1/endpoints/trade.py`（新增，prefix `/trade`）
- `GET /trade/accounts/{account_id}/positions` — 该账户真实持仓（路由+登录+读）
- `GET /trade/accounts/{account_id}/orders` — 挂单
- `GET /trade/accounts/{account_id}/deals?start&end` — 成交回报
- `POST /trade/order` — 市价单（风控闸+审计）
- `POST /trade/close` — 平仓（可部分）
- `POST /trade/cancel` — 撤挂单
- 读端点同样做账户归属校验（非本人 → 404）。

### 前端 `/trading/manual` 页（新增）
- 顶部：账户下拉（useAccounts，显示 login@server·节点）+ 品种输入。
- 下单票：买/卖方向、手数、滑点，二次确认弹窗（真实资金），提交后展示 retcode。
- 持仓表：ticket/方向/手数/开仓价/现价/浮动盈亏 + 「平仓」按钮（全平/自定义手数）。
- 挂单表：ticket/类型/手数/价格 + 「撤单」按钮。
- 成交表：近 N 笔 deals。
- 路由 `/trading/manual` + 导航项「手动交易」（实盘开启时显示，与 LIVE_NAV 同区）。
