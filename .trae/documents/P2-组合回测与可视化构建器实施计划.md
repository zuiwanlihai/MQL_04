# P2 切片实施计划：多品种组合回测 + 可视化策略构建器

> PRD Phase 3 远期项（剩余开发记录.md L25-26）。PRD 仅有目录级定位、无详细需求，
> 本计划自行定义 MVP 范围。两项互相独立，可分两个切片交付。

## 调研结论（方案选型依据）

### 多品种组合回测
- 单品种假设贯穿全链路：`BacktestTask.symbol` 单值（models/backtest.py 注释明确
  "Single symbol for MVP backtests"）→ queue payload `symbol/symbol_info` 单值 →
  `BacktestContext` 单 `_symbol`，`get_bars/get_quote` 严格 symbol 匹配否则返回空。
- **引擎层多品种深改（方案 A，否决）**：改 matching/Context/下单接口带 symbol、
  共享资金池多品种撮合——冲击面覆盖三态引擎与三态对账门禁，风险与工作量远超 P2 切片承载。
- **平台层聚合（方案 B，采用）**：复用 WF/optimization 已验证的「父任务 + 子回测任务 +
  config_snapshot 关联 + 读时聚合」模式（先例：kind=walk_forward 子任务带 analysis_id/analysis_role）。
  每品种一个真实单品种子回测（引擎零改动），组合视角在读取时聚合。

### 可视化策略构建器
- 策略源码形状稳定：`on_init(ctx)` 里 `ctx.declare(symbol, period, params)`，
  `on_bar(ctx, bar)` 里 `ctx.get_bars` → 指标计算 → `ctx.buy(ctx.symbol, volume)` /
  `ctx.close(pos.id)`（参考模板 double_ma.py）。纯 stdlib + ctx API，必然过
  strategy_validator 白名单校验。
- 前端无拖拽库（package.json 确认）。引入 react-flow 画布属于过度设计——
  **分层积木拼装**（指标层 → 条件层 → 动作层）+ 原生 HTML5 DnD 排序即可满足
  「拖拽无代码」，且生成的策略结构天然是线性的。

## 切片 1：多品种组合回测

### 范围
- 仅回测（PRD 也只定位「组合回测」）；模拟盘/实盘组合不在本切片。
- 组合 = 一个策略 × N 个品种（2~8）× 同一 timeframe，资金均分（等权）。
- 组合报告：合并权益曲线 + 组合指标 + 分品种下钻。

### 后端
1. **新模型 `PortfolioBacktest`**（models/portfolio.py）：
   - 字段：`user_id`(FK CASCADE) / `strategy_id`(FK strategies, RESTRICT) /
     `symbols`(JSONB list, 2~8) / `timeframe` / `total_deposit` / `spread_mode` /
     `commission_per_lot` / `slippage_points` / `status`(running|completed|failed) /
     `params`(JSONB：品种→子任务映射) / `result`(JSONB，终态缓存聚合) /
     `error`(Text)。
   - 迁移：新表 + 索引（user_id, created_at）。
2. **创建端点 `POST /backtests/portfolios`**（字面量路由，注册在 `/{task_id}` 之前）：
   - 校验策略 owner + 状态可回测、品种 2~8 去重、total_deposit 上限。
   - 建 1 个 portfolio 行 + N 个真实 `BacktestTask`（每品种一个）：
     `initial_deposit = total_deposit / N`，`config_snapshot` 带
     `portfolio_id` + `role=symbol 名`，走现有串行队列原样执行。
   - 复用现有回测任务的风控/额度校验逻辑。
3. **列表/详情端点**：
   - `GET /backtests/portfolios`（分页，含各子任务状态摘要）。
   - `GET /backtests/portfolios/{id}`：读时聚合——全部子任务 completed 时：
     各子任务拉权益曲线逐时间戳对齐合并（并集 + 前值填充）→ 组合 equity 序列 →
     算总收益/年化/夏普/最大回撤 + 分品种明细 → 缓存 result；任一 failed →
     portfolio failed（error 注明失败品种，其余子任务结果仍可下钻查看）。
   - running 状态轮询同 WF 模式（前端复用轮询 hook）。

### 前端
4. **组合创建对话框**：策略选择 + 品种多选（tag 输入，2~8）+ timeframe +
   总资金/成本配置（复用 BacktestCreateDialog 字段风格）。
5. **回测列表页**：顶部 tab 或区块「组合回测」，列表行显示品种 chips + 聚合状态 +
   子任务完成进度（2/5）。
6. **组合报告页** `/backtest/portfolio/:id`：组合权益曲线（EquityChart 复用）+
   组合指标卡 + 分品种收益对比条形图 + 子任务列表（点击跳单品种报告页）。

### 测试
- 后端：创建校验（品种数/策略 owner/资金均分）、读时聚合（伪造多子任务权益曲线
  合并正确性）、failed 传播、路由顺序。
- 前端：npm build + vitest（聚合函数单测如有纯函数抽取）。

## 切片 2：可视化策略构建器

### 范围
- 生成「单品种趋势/均值回归」策略子集（对标 double_ma.py 结构）：
  指标计算 → 开仓条件 → 平仓条件 → 资金手数 → 一次一仓风控。
- 不支持网格/对冲等复杂结构（生成的代码进编辑器后用户可手改扩展）。

### 积木 DSL（前端 TS 定义）
- **指标块**：MA/EMA/RSI/BOLL/ATR/MACD，参数可配（周期等），输出变量名自动编号。
- **条件块**：cross_above / cross_below / greater_than / less_than，左右操作数
  （指标输出 | 价格 close）。
- **动作块**：开多（无持仓时）、平多、开空、平空（与条件绑定）。
- **全局**：品种/周期、手数、方向限制（long_only/short_only/both，联动 Strategy.direction）。

### 实现
1. **代码生成器 `lib/builder/codegen.ts`（纯函数，可单测）**：积木 JSON →
   Python 源码字符串（模板字面量渲染，风格对齐 double_ma.py：
   params 进 declare、get_bars 取数、逐指标计算、条件判断、ctx.buy/close）。
2. **新页面 `/strategies/builder`**：
   - 左侧积木面板（指标/条件/动作分组），中间分层积木列表（HTML5 drag & drop
     排序 + 点击配置参数），右侧实时预览生成代码（只读 Monaco）。
   - 「保存为策略」→ `builder_config` 随创建/更新提交。
3. **`strategies.builder_config` 新列**（JSONB nullable，迁移）：
   - Strategy schema 增可选字段；再次进入构建器可加载积木继续编辑。
   - 手改过源码的策略（builder_config 与 source 不再严格对应）打开构建器时
     提示「将覆盖现有源码」。
4. **入口**：策略列表页「可视化构建」按钮 + 侧栏新增入口。

### 测试
- codegen 单测（vitest）：各积木组合 → 快照断言生成代码形状；
  生成代码必须包含 declare/on_bar/buy/close 关键结构。
- 手动 E2E：构建 → 保存 → 编辑器校验通过 → 跑一次真实回测出报告。

## 交付顺序与门禁

- 建议 **先切片 1（组合回测）**：后端价值独立、风险集中在聚合正确性；
  切片 2 纯前端为主、无迁移耦合。两项都做时按 1 → 2 串行。
- 每切片门禁：后端 ruff + pytest 全量、前端 tsc build + vitest、浏览器 E2E
  （组合回测跑真实 2 品种子任务出组合报告；构建器生成策略真实回测）。
- 硬约束复检：路由字面量先于 uuid 路由、迁移与模型 CheckConstraint 同步
  （本切片无枚举扩展，风险低）、portfolio 子任务复用真实队列串行执行
  （N 品种 = N 个子任务，受现有并发上限约束）。

## 明确不做（本切片外）
- 引擎原生多品种（共享资金池撮合）、模拟盘/实盘组合、组合层风控规则、
  权重非等权的资金分配、构建器支持自定义指标块、react-flow 画布。
