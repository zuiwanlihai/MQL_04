> PRD 3.0 功能地图「策略研发 → Jupyter 研究笔记本 ... P1」，Phase 2 收尾切片。
> 自研轻量笔记本（非 Jupyter Server）：backend venv pip 损坏无法安装新依赖，且复用现有沙箱/子进程基建。

## 0. 调研结论

| 复用面 | 现状 |
|---|---|
| 静态校验 | `services/strategy_validator.py` 白名单 import / 危险 builtin / 逃逸成员检查完备，但含策略回调要求（on_init/on_bar），笔记本需独立轻量校验入口 |
| 运行时 import 钩子 | `sandbox/import_hook.py` 可直接复用（install/uninstall） |
| 子进程监督 | `sandbox/runner.py` 模式：payload 目录 + JSONL stdout + stdin beacon + 退出码；超时/RSS 看门狗在队列侧 |
| 取数 | `gateway_client.rates(name, timeframe, limit)` / `rates_range` 现成，get_bars 直接注入 |
| 依赖 | numpy/pandas/scipy 可用；**无 matplotlib**（pip 损坏）→ 图表走「内置 plot() 输出结构化数据 + 前端 lightweight-charts 渲染」 |
| 竞品定位 | 研究笔记本 = 回测前的探索工具：拉行情、算指标、画图、验证想法，再沉淀为策略代码 |

## 1. 数据模型（backend）

- 新表 `notebooks`：`id`(uuid PK)、`user_id`(FK users, 索引)、`title`(varchar 200)、`cells`(JSONB)、`created_at`、`updated_at`
  - cells 结构：`[{id, type: 'code'|'markdown', source, outputs: [...]}]`；outputs 随保存持久化（所见即所得），单 cell outputs 上限 64KB、单本 notebook 上限 100 cell（守卫）
- 迁移：`xxxx_m18_notebooks.py`（head 基于 `e5a1c7d9f204`）
- 模型放 `app/models/notebook.py`，`MappedAsDataclass` 顺序遵守项目约束

## 2. 执行内核（核心）

### 2.1 会话模型
- `services/notebook_kernel.py`：进程内 `_sessions: dict[notebook_id, SessionMeta]`（状态文件路径、last_used、锁）
- 状态持久化：`DATA_DIR/notebook_sessions/{notebook_id}/state.pkl`（globals pickle）；执行 per notebook 串行（asyncio.Lock），全局并发上限 2（Semaphore）
- 空闲 TTL 30min：lifespan 循环清理会话目录（复用现有 lifespan 模式）
- 重启内核 = 删状态目录

### 2.2 子进程执行（per cell）
- 新 `sandbox/notebook_runner.py`（`python -m app.sandbox.notebook_runner --payload <dir>`）：
  1. 恢复 `state.pkl`（存在则 loads 为 globals，否则全新 dict + 注入内置）
  2. 编译执行 cell source（`exec(compile(...), globals)`）
  3. 捕获：stdout（tee 到 JSONL 事件）、末表达式值 repr、异常 traceback（截断）
  4. 保存 state.pkl → 输出 `{"event":"done", outputs:[...]}` → exit 0
  - stdin beacon（父亡即退）与 BLAS 单线程 pin 照抄 runner.py
- 父侧监督：30s 超时（可配 NOTEBOOK_CELL_TIMEOUT_SECONDS）、RSS 上限（复用回测看门狗阈值）、超时 kill 后会话状态标记 poisoned → 下次执行前强制重置
- 内置注入（不可 import，直接进 globals）：
  - `get_bars(symbol, timeframe='H1', count=500) -> pd.DataFrame`（网关 rates，columns: time/open/high/low/close/volume/spread）
  - `plot(df_or_series, columns=None, title='')` → 输出 `{"kind":"chart","series":[...]}` 事件（前端渲染），单 cell 最多 4 张
- 白名单：import 检查复用 strategy_validator 白名单集合（新建 `validate_notebook_source()`：只查 import/危险 builtin，不查策略回调）；运行时挂 import_hook

## 3. API（/notebooks 前缀，字面量路由全部注册在 /{notebook_id} 之前）

| 端点 | 说明 |
|---|---|
| GET `/notebooks` | 当前用户列表（id/title/updated_at/cell 数） |
| POST `/notebooks` | 创建（title 必填） |
| GET `/notebooks/{id}` | 详情含 cells（跨用户 404） |
| PATCH `/notebooks/{id}` | 保存 title/cells（大小/数量守卫） |
| DELETE `/notebooks/{id}` | 删除（级联清会话目录） |
| POST `/notebooks/{id}/run` | body `{cell_id, source}`；同步执行（超时 35s）→ 返回 outputs + 内核状态；409 = 会话 poisoned 重置中 |
| POST `/notebooks/{id}/restart` | 清空会话状态 |

- schemas：`NotebookOut/NotebookDetailOut/NotebookRunOut`（Out schema 用 float 惯例不涉及，全 str/list/dict）

## 4. 前端

- `useNotebooks.ts` hooks：list/create/get/update/del/run/restart（run 超时 120s）
- `NotebookListPage`（/notebooks）：列表 + 新建（镜像 StrategyListPage 风格）
- `NotebookDetailPage`（/notebooks/:id）：
  - cell 列表：code cell = 自动增高 textarea（等宽）+ 运行按钮 + Ctrl+Enter 执行；markdown cell = textarea 编辑 + 只读原文展示
  - 输出区：stdout 文本（pre wrap）、表达式 repr、chart 用 lightweight-charts line series 渲染（复用已有依赖）、错误红字
  - 顶部：标题编辑、保存状态（1200ms 防抖 PATCH）、内核徽标（idle/busy/stale）、重启内核、添加代码/文本 cell、上下移/删除 cell
  - 路由懒加载 + Suspense 边界（项目硬约束）；侧栏加「研究笔记」入口

## 5. 任务队列监控（系统管理 P1 小补，并入本切片）
