**涨跌配色改动的精确边界（探查结论）**：
- 「涨跌**方向**色」应随开关翻转，仅两处真源：
  - [market.ts](file:///e:/SRE/mql/MQL_04/frontend/src/lib/market.ts) `changeClass()`（被 QuoteTable、SymbolDetail 使用）

  与「涨跌方向」是两回事，**不随开关翻转**（PRD 只要求 K 线/涨跌幅惯例可切）。
- [Charts.tsx](file:///e:/SRE/mql/MQL_04/frontend/src/components/backtest/Charts.tsx) 的 `#ef4444` 是回撤曲线（语义=下跌），不翻转。

## Phase A — 主题 store + 涨跌方向色接入 + 系统设置页

### A1 `store/useThemeStore.ts`（新建）
- zustand + persist（key `mt5quant.theme`）：`redUpGreenDown: boolean`（默认 true，保持现状国内惯例）、`setRedUpGreenDown(v)`、`toggle()`。

### A2 方向色改读开关
- `changeClass(value)` → `changeClass(value, redUpGreenDown)`（纯函数加参，默认参 true 保持向后兼容）；
  QuoteTable / SymbolDetail 两处调用点从 `useThemeStore` 取 `redUpGreenDown` 传入。
- KlineChart：`useThemeStore` 取 `redUpGreenDown`；`upColor/downColor` 依开关取 `#ef4444`/`#22c55e`；
  新增 effect 依赖 `redUpGreenDown` → `seriesRef.applyOptions({upColor,...})` 即时重涂（不销毁重建图表）。

### A3 `pages/Settings/SystemSettingsPage.tsx`（新建，`/settings/system`）
- 个人资料卡：用户名/邮箱/全名/角色（中文映射）/注册时间（来自 `useAuthStore.user`，只读展示）。
- 交易外观卡：红涨绿跌开关（toggle）+ 实时预览（涨/跌两枚样例数字随开关换色）。
- 平台信息卡：平台名、版本（`import.meta.env` 或常量 v0.1）、模块清单只读概览。

门禁 A：`npm run build` 零类型错误；手动核对开关切换后 QuoteTable/SymbolDetail/K线 同步换色、盈亏语义色不变。
