## 设计决策

### 登录两步流（stateless，不落服务端会话态）
1. `POST /auth/login`：验邮箱+密码。**未开启 2FA** → 直接签发 SessionResponse（现状不变）。
   **已开启 2FA** → 不签发正式会话，返回 `{requires_2fa:true, pre_auth_token:<短时JWT>, ttl_seconds:300}`。
   pre_auth_token 为访问令牌但带 `purpose:"2fa_pending"` claim、5 分钟过期，**不含** sid（不能访问业务接口）。
2. `POST /auth/login/2fa`：body `{pre_auth_token, totp_code}`。验 pre_auth_token 的 purpose+签名 → 验 TOTP（或恢复码）
   → 签发正式 SessionResponse（创建 UserSession 行）。恢复码命中则消耗该码并置 `recovery_code_used:true`。

### 密钥存储
- `totp_secret` 存 **Fernet 密文**（复用 encrypt_secret），列加宽到 String(255)。明文只在 setup 步骤一次性返回给前端做二维码。
- 新增 `recovery_codes: JSONB`（默认 `[]`）：存 10 个恢复码的 **sha256 十六进制摘要**（明文只在 enable 时一次性返回）。
- `totp_enabled: Boolean`（已有列，启用后置 True）。

### setup/enable/disable（均需已登录，写审计）
- `POST /auth/2fa/setup`：生成随机 secret → Fernet 加密暂存 `totp_secret`（**不改 totp_enabled**）→
  返回 `{secret(明文), otpauth_uri, qr_png_base64}`。用户扫码后进入待验证态。
- `POST /auth/2fa/enable`：body `{code}`。用暂存 secret 验 code（±1 时间窗）→ 正确则 `totp_enabled=true`，
  生成 10 个恢复码存摘要、返回明文清单。审计 `2fa_enable`。
- `POST /auth/2fa/disable`：body `{password}`（重确认）。验密码 → `totp_enabled=false`、清空 secret/recovery_codes。
  审计 `2fa_disable`。
- `GET /auth/2fa/status`：返回 `{enabled: totp_enabled, recovery_codes_remaining: N}`（供设置页展示，不含密钥）。

## Phase A — 后端：迁移 + totp 服务 + 登录两步 + setup/enable/disable + 审计

### A1 迁移（新建 alembic revision，revises=7b8a03a36663）
- `op.alter_column('users','totp_secret', type_=sa.String(255), existing_type=sa.String(64))`
- `op.add_column('users', sa.Column('recovery_codes', postgresql.JSONB(), nullable=False, server_default=sa.text("'[]'::jsonb")))`
- downgrade 反向。执行 `alembic upgrade head`。

### A2 `app/services/totp.py`（新建）
- `new_secret()` → base32 str；`provisioning_uri(email, secret, issuer='MT5量化平台')`；
  `qr_png_data_uri(secret, uri)` → base64 PNG（qrcode，用于前端 <img>）
- `verify_code(secret, code, valid_window=1)` → bool；`gen_recovery_codes(n=10)` → list[str]；
  `hash_codes(list)` → list[sha256]；`match_recovery_code(hashed, input)` → (bool, index)

### A3 schemas（`app/schemas/auth.py`）
- `TwoFAChallenge{requires_2fa:bool=True, pre_auth_token:str, ttl_seconds:int}`
- `LoginResponse` 判别联合（SessionResponse | TwoFAChallenge）——login 端点 `response_model=None` 手工返回
- `LoginTwoFARequest{pre_auth_token, totp_code}`；`TwoFASetupOut{secret, otpauth_uri, qr_png_base64}`；
  `TwoFAEnableRequest{code}`；`TwoFAEnableOut{recovery_codes:list[str]}`；`TwoFADisableRequest{password}`；
  `TwoFAStatusOut{enabled, recovery_codes_remaining}`
- `UserResponse` 增 `totp_enabled: bool`

### A4 security 服务（`app/services/security.py`）
- `create_pre_auth_token(user_id, ttl=300)`：JWT 带 `purpose:"2fa_pending"`、无 sid；
- `decode_pre_auth_token(token)`：校验 purpose+签名，返回 sub；不符抛 401。

### A5 端点（`app/api/v1/endpoints/auth.py`）
- 改 `login`：密码验证通过后按 `user.totp_enabled` 分支（未开启=原路径；开启=返回 challenge，**不建 UserSession**）
- 新增 `POST /auth/login/2fa`、`POST /auth/2fa/setup|enable|disable`、`GET /auth/2fa/status`
- login 成功/失败、2fa 成功/失败均 `audit_record("login"/"login_2fa", params={result, via:"totp|recovery|none"})`

### A6 服务层（`app/services/auth.py`）
- `authenticate_user` 拆分：先 `verify_password` → 若 totp_enabled 返回 pre-auth（不 _issue_session）；否则原样签发。
- `complete_2fa_login(db, pre_auth_sub, code)`：解密 secret 验 TOTP，失败再试恢复码（命中则从 recovery_codes 移除该摘要），
  都失败 → 401；成功 → _issue_session。
- setup/enable/disable/status 服务函数（enable 前 secret 必须已暂存）。

门禁 A：新增 `tests/test_auth_2fa.py`（setup→enable→login 两步成功 / 错误码拒绝 / 恢复码单次消耗 /
disable 需密码 / **未开启 2FA 用户登录响应结构不变** / pre_auth_token 不能当访问令牌用 / 审计留痕）。
全量 pytest（236+新增）+ ruff 绿。

## Phase B — 前端：登录两步 UI + 系统设置页 2FA 卡

### B2 登录页（`pages/Login.tsx`）
- 第一步邮箱+密码提交；若响应 `requires_2fa` → 切到第二步：6 位验证码输入框（可切换「使用恢复码」）+ 返回上一步。
- 无 2FA 用户流程完全不变。

### B3 系统设置页 2FA 卡（`pages/Settings/SystemSettingsPage.tsx` 内新增 section）
- 状态展示：已启用（含剩余恢复码数）/ 未启用。
- 启用向导：点「启用」→ `POST /auth/2fa/setup` → 显示二维码（`<img src=qr_png_base64>`）+ 手动密钥（可复制）→
  输入验证器当前 6 位码 → `POST /auth/2fa/enable` → 一次性展示 10 个恢复码（提示保存）→ 完成刷新状态。
- 停用：输入账号密码重确认 → `POST /auth/2fa/disable`。

### B4 hooks（`hooks/useAuth2fa.ts` 新建）
- `use2FAStatus()`、`useSetup2FA()`、`useEnable2FA()`、`useDisable2FA()`（mutation + invalidate 认证/me）。

3. 浏览器 E2E（localhost:3000）：

   - 错误码被拒；恢复码可登录一次后再次使用失败。
   - 停用 2FA（需密码）→ 恢复一步登录。
