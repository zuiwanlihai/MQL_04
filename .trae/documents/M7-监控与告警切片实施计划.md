# M7 监控与告警 切片实施计划

## Context（为什么做）

M1–M6 已交付：认证、行情、策略研发、回测、模拟盘、实盘部署+风控中心后端全部就位。
M6 已把数据模型与写入侧打通（`live_runs` 账户/持仓镜像、`equity_history`、`alert_events`、
`audit_logs` 哈希链、`risk_rules/risk_events`、`gateway_nodes` 心跳），但**前端监控面全是占位页**：
`/risk`、`/risk/audit`、`/alerts` 三个路由是「建设中」，`/dashboard` 还是认证切片时代的静态页。

M7 = PRD「监控与告警」垂直切片，把这些只读展示面做实：
- **仪表盘**（登录后首页）：账户净值/今日盈亏大数字、当日权益曲线、持仓列表、运行中策略卡片（状态灯）、网关健康、告警滚动条
- **告警中心**：告警列表 + 已读 + 轮询（后端 `/live/alerts` 已存在，前端未接）
- **风控中心 UI**：规则 CRUD + 风控事件 + 冻结账户解冻 + 降级复核（后端 `/live/rules|risk-events|accounts/{id}/unfreeze|{id}/re-admit` 已存在）
- **审计 UI**：审计日志查询（按时间/主体/动作/目标过滤）+ 链完整性校验徽章 + CSV 导出（导出行为本身记审计）

**风险等级**：M7 以只读展示为主，唯一写侧是「审计查询/校验/导出 + 告警已读」，不触碰资金执行路径，
故直接执行（区别于 M6 的资金风险走 plan mode 审批）。

**无需 alembic 迁移**：所有表（audit_logs / alert_events / live_runs / mt5_accounts /
gateway_nodes / risk_rules / risk_events）M6 已建，head=7b8a03a36663 不变。

**已知边界（M7 不做，P1）**：邮件/Telegram/钉钉/企微 告警渠道（`alert.py` 里 email 是 logged no-op）；
审计归档与「单时间点回看时间线视图」；多用户租户隔离（Phase 1 单租户，但审计查询按 admin 鉴权）。

硬约束（沿用）：全中文 UI；懒加载路由包 Suspense；MappedAsDataclass 在 DeclarativeBase 前；
default_factory；PowerShell 用 `;` 不用 `&&`；命令绝对路径；FastAPI 字面量 GET 注册在 uuid 路径参数前。

## Phase A — 后端：审计查询/校验 + 仪表盘聚合

### A1 审计端点（新建 `app/api/v1/endpoints/audit.py`，前缀 `/audit`，admin 鉴权）
- `GET /audit`：分页 + 过滤（`start`/`end` UTC ISO、`actor_id`、`action`、`target_type`、`target_id`、
  `result`）；`_require_role(("admin",))`；只读，不改链。返回 `AuditListResponse`（items/total/page/…）。
- `POST /audit/verify`：调 `services.audit.verify_chain()` → `(total, first_broken_index)`；
  若 broken≥0 → `services.alert.emit(source="audit_chain", level="critical", …)` 产生「审计链校验失败」告警；
  校验结果本身 `audit_record("audit_verify", …)`；返回 `{total, ok, broken_index, checked_at}`。
- `GET /audit/export?format=csv|json`：按同样过滤导出；**导出行为记审计** `audit_record("audit_export", …)`；
  CSV 用 `StreamingResponse`（`text/csv`，BOM 头防 Excel 乱码）。
- schemas 新建 `app/schemas/audit.py`：`AuditOut`（全字段+hash 摘要）、`AuditListResponse`、`AuditVerifyOut`。

### A2 仪表盘聚合端点（新建 `app/api/v1/endpoints/dashboard.py`，前缀 `/dashboard`）
- `GET /dashboard/overview`：只读聚合当前用户数据，一次请求喂满首页。返回 `DashboardOut`：
  - `accounts[]`：本人 MT5Account 镜像（login/name/type/currency/balance/equity/margin_level/is_connected）
  - `totals`：`equity`=Σ账户净值、`today_pnl`=Σ运行中 live_runs (equity−day_start_equity)、
    `unrealized_pnl`=Σ运行中 live_runs unrealized、`running_live`/`running_paper` 计数
  - `equity_curve[]`：当日分时权益——取运行中 live_runs 的 `equity_history`（过滤 time≥今日 UTC）合并；
    无实盘时回退运行中 paper_runs 的 equity_history
  - `positions[]`：运行中 live_runs 的 `positions` 镜像（ticket/symbol/type/volume/price/profit/magic）
  - `live_runs[]`：运行中+暂停+降级 的实盘卡片（id/strategy_name/status/symbol/timeframe/equity/
    unrealized_pnl/demoted/no_new_orders/observation_ends_at/capital_cap_pct/last_bar_time）
  - `gateway`：主节点 `GatewayNode`（status/last_heartbeat/cpu/memory/active_sessions/version）
  - `alerts[]` + `alerts_unread`：最近 10 条 AlertEvent（复用现有模型）
- 复用 `select(Strategy.name).where(Strategy.id==run.strategy_id)` 批量取策略名（一次 join）。
- schemas 新建 `app/schemas/dashboard.py`。

### A3 注册路由（`app/api/v1/router.py`）
- `include_router(audit_router, prefix="/audit", tags=["audit"])`
- `include_router(dashboard_router, prefix="/dashboard", tags=["dashboard"])`

门禁 A：新增 `tests/test_audit_api.py`（列表过滤/verify 完好链/verify 篡改链触发告警/export 记审计/admin 鉴权 403）
