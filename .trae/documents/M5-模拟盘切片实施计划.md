# M5 模拟盘（Paper Trading）切片实施计划

## Context
PRD M5 定义「模拟 & 实盘交易」。全量 M5（实盘四闸+部署向导+观察期+对账）过大，按 M3/M4 惯例本切片只交付 **模拟盘 Paper Trading**——实盘准入闸③④的前置底座，复用 M4 撮合内核（一致性原则）。

## 已核实事实（权威依据）
- 无 WebSocket 基建：前端全部 react-query `refetchInterval` 轮询。
- 网关只有只读行情 HTTP 端点：`rates_range(name, tf, start, end, limit)` 返回升序 `[start,end)` 收盘 bar；`symbols()` 含品种信息。无交易端点。
- `BacktestEngine` 是纯库（docstring 明示 M5 可复用），但 `run()` 为全量回放形态（末根强平→done report）→ 需要增量驱动。
- `install_all()` 修改全局解释器状态 → 模拟盘策略必须跑**长驻子进程**（复用 M4 runner 模式），控制指令走 stdin。
- `config.py` 已预留 `DEFAULT_PAPER_DURATION_DAYS=14`、`SANDBOX_CALLBACK_TIMEOUT_LIVE=1`。
- `router.py` L48/53、`models/__init__.py` L23、前端 `routes.tsx` L47 `/trading/paper` 均为占位待接。
- SDK `mode` 含 "paper"；`ctx.storage` 恢复契约=仅恢复 storage。
- M4 修复：子进程 stdout `limit=STREAM_LIMIT(1_100_000)`（supervisor.py），paper 必须沿用。
- 硬约束：MappedAsDataclass 在 DeclarativeBase 前；mapped_column 用 default_factory；懒加载路由包 Suspense；测试用 `backend\.venv\Scripts\python.exe -m pytest`。

## 设计决策
1. **撮合档位**：paper 仅允许 `standard | optimistic`（conservative 需次根开盘价，增量模式无未来 bar）。复用 FillModel/AccountSim 不改动。
2. **执行体**：长驻子进程 `python -m app.sandbox.paper_runner --payload <dir>`，payload 目录复用 `save_payload`（payload.json + bars.npz，含启动时预取的历史 bar 序列）。
3. **控制协议（stdin JSONL 指令 / stdout JSONL 事件）**：
   - 子进程启动：装载策略→on_init→逐根回放历史 bars（warmup 期拒单，不强平）→进入 live 循环阻塞读 stdin。
   - `{"cmd":"bars","bars":[[t,o,h,l,c,v,sp],...]}` 增量喂收盘 bar → 逐根 on_bar+估值+stop-out。
   - `{"cmd":"pause"}` / `{"cmd":"resume"}`：暂停=父进程停止发 bar，子进程回 `state` 事件。
   - `{"cmd":"stop","close":true|false}`：可选按最后收盘价强平全部持仓→on_stop(reason)→发终态 account→exit 0。
   - `{"cmd":"status"}`：立即回 account+positions 快照。
   - 事件 kind：`log|signal|trade|account|positions|state|fail`（与 M4 对齐；account 事件含 balance/equity/margin_used/margin_free/unrealized_pnl/last_bar_time）。
   - 每根 bar 处理后把 `ctx.storage._data` 落盘 `storage.json`（恢复契约）。
   - 退出码：0=stop、2=安全终止、3=装载失败、143=父进程消失（stdin EOF beacon 沿用）。
4. **父端 manager**（`app/services/paper/manager.py` 单例，lifespan 挂载）：
   - start：取 symbol_info+历史（warmup_bars+100 根，rates_range）→payload 落盘→spawn→`_stream` 任务持久化事件 + `_poll` 任务每 `PAPER_POLL_SECONDS=10` 秒取新收盘 bar（bar.time+tf_seconds<=now 才算收盘）发 stdin。
   - pause/resume/stop/reset：CAS 状态 + 发指令；reset=stop+清 trades/logs+重置 run 行+重新 start。
   - 事件持久化：log→paper_logs、trade→paper_trades、account→更新 run 行（balance/equity/positions JSONB/equity_history 追加，上限 5000 点）。
   - startup_sweep：running/paused→failed（「服务重启导致模拟盘中断」）。
   - RunnerSupervisor 扩展：`run(on_event, timeout=None)`（None=无总时限）+ `send(cmd: dict)` 写 stdin。
5. **数据模型**（仿 models/backtest.py）：`PaperRun`（状态 running|paused|stopping|stopped|failed）、`PaperTrade`、`PaperLog`（无 report 表；equity_history JSONB 存 run 行）。
