# 监控与告警交付后验证清单（M7）

> 适用范围：MT5 量化交易平台「监控与告警」切片（仪表盘 / 告警中心 / 风控中心 UI / 审计 UI）交付后的运维核对。
> 基于实际实现编写：`/dashboard/overview` 单请求聚合 / `/audit` 查询-校验-导出三端点（admin）/ `/live/alerts/read-all` / 前端四页 + 角色控权。
> 环境约定：后端 `http://127.0.0.1:8000`，网关 `http://127.0.0.1:8090`，前端 `http://localhost:3000`；API 需 `Authorization: Bearer <access_token>`。
> 使用方式：每行勾选框后附验证手段（UI 路径 / 命令 / 接口）。标注 🔴 的项失败时**按最高优先级缺陷处理**（审计缺失 = 责任无法界定，与风控失效同级）。
> 账号提示：审计/解冻/降级复核仅 **admin** 可用；首个注册用户自动 admin，其余账号需提权后验证。

## 1. 仪表盘（/dashboard，登录后首页）

- [ ] 四个大数字卡为**真实数值**（非「—」占位）：
  | 卡片 | 口径（已实现语义） |
  |---|---|
  | 账户净值 | Σ 本人绑定 MT5Account.equity（真实账户镜像，**非**各 run equity 之和——同账户多策略不重复计） |
  | 今日盈亏 | Σ 活动实盘 (equity − day_start_equity)，仅 `day_start_date=今日UTC` 的 run 计入 |
  | 浮动盈亏 | Σ 活动实盘 unrealized_pnl（= equity − balance） |
  | 运行任务 | running 实盘 + running 模拟；降级数单独在 sub 行显示 |
- [ ] 日切正确性：跨 UTC 零点后，旧 day_start 的 run 今日盈亏归 0（次日由 manager 重新钉 day_start_equity）
- [ ] 当日权益曲线：取活动实盘 `equity_history` 中 **time ≥ 今日 UTC 零点** 的点合并；无实盘时回退活动模拟盘曲线；历史点（跨日）不得混入
- [ ] 持仓列表：来自各活动 run 的 `positions` 镜像（ticket/方向/手数/现价/浮盈），与 MT5 终端「交易」页一致（≤ `LIVE_POLL_SECONDS` 延迟）
- [ ] 运行中策略卡片状态灯：绿=running / 蓝=pending / 黄=paused|stopping / 灰=stopped / 红=failed **或 demoted**；徽章含「已降级/停止开仓/待对账/观察期 N%」
- [ ] 卡片点击跳转实盘详情页；「进入实盘中心」「全部 →」链接可达
- [ ] 告警滚动条：最近 10 条 + 未读计数；级别色点 info蓝/warn黄/error橙/critical红
- [ ] 轮询节奏：存在 running 实盘时 5s 刷新；空闲时 30s（DevTools Network 观察 `/dashboard/overview` 间隔）
- [ ] 多用户隔离：A 用户看不到 B 用户的账户/实盘/持仓（overview 按 `user_id` 过滤；告警为平台级共享）

| 断链告警不自动重发 | 校验由人工点击/未来定时任务触发；M7 未上自动巡检（P1 定时化后可加） |
